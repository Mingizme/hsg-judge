# HSG Judge - Nền tảng Luyện thi HSG Tin Học

Nền tảng luyện thi và đánh giá kỹ năng lập trình dành cho học sinh giỏi tin học.

## Architecture

- **Frontend**: Next.js (Deployed on Vercel)
- **Backend**: NestJS (Deployed on Render)
- **Database**: Supabase (PostgreSQL)
- **Judge Environment**: Judge0

## Getting Started

1. Clone the repository
2. Install dependencies:
   - Frontend: `cd frontend && npm install`
   - Backend: `cd backend && npm install`
3. Setup Environment Variables
   - Copy `.env.example` in frontend and configure.
   - Configure backend env vars according to `.env.example` (if any) or deployment docs.
